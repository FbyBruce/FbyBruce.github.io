背景

每次打开PowerShell都需要很长的时间加载个人配置文件，这是因为在使用conda init后，在每次打开PowerShell时会自动进行 conda 初始化，此时会注入大量脚本导致加载速度很慢。

可以在PowerShell中执行$PROFILE查看配置文件的位置，比如：

PS E:\Develop\Projects> $PROFILE
C:\Users\13665\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1

但进入目录会发现，没有Microsoft.PowerShell_profile.ps1，只有profile.ps1，其实名字不影响。打开配置文件内容如下：

#region conda initialize
# !! Contents within this block are managed by 'conda init' !!
 If (Test-Path "E:\Develop\Kits\anaconda3\Scripts\conda.exe") {
     (& "E:\Develop\Kits\anaconda3\Scripts\conda.exe" "shell.powershell" "hook") | Out-String | ?{$_} | Invoke-Expression
 }
#endregion

解决方案

注释掉 profile 中自动初始化 Conda 的代码，然后创建一个快捷命令手动激活：

# -------------------------
# 延迟加载 Conda - Lazy Load
# -------------------------
function enter-conda {
    $CondaPath = "E:\Develop\Kits\anaconda3\shell\condabin\conda-hook.ps1"
    if (Test-Path $CondaPath) {
        Write-Host "Initializing Conda..." -ForegroundColor Cyan
        . $CondaPath
        # 可选：自动激活 base 环境
        conda activate base
    } else {
        Write-Warning "Conda 脚本未找到: $CondaPath"
    }
}

# （可选）创建别名快速进入
Set-Alias conda-init Enter-Conda

上面的CondaPath部分需要对应自己电脑上的 conda 可执行文件和脚本位置

下面是查找自己电脑上真正的 conda 可执行文件和脚本位置：

  • 运行：
Get-Command conda
  • 输出示例：
CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
ExternalCommand conda.exe                                          0.0.0.0    E:\Develop\Kits\anaconda3\condabin\conda.exe
  • 记下 Source 路径，比如是：
E:\Develop\Kits\anaconda3\condabin\conda.exe
  • 那对应的 hook 脚本应该在这个目录下：
E:\Develop\Kits\anaconda3\shell\condabin\  # 或
E:\Develop\Kits\anaconda3\shell\           # 新版 Conda 放在这里
  • 所以请运行以下命令查找真实存在的 hook 文件：
# 尝试查找所有叫 conda-hook.ps1 的文件
Get-ChildItem "E:\Develop\Kits\anaconda3" -Recurse -Name -Include "conda-hook.ps1" -ErrorAction SilentlyContinue
  • 常见结果可能是：
shell\conda-hook.ps1
  • 即完整路径为：
E:\Develop\Kits\anaconda3\shell\conda-hook.ps1

保存并重启PowerShell，打开PowerShell会飞快启动，因为没有加载Conda，只有当手动输入运行enter-conda时才会真正初始化Conda
